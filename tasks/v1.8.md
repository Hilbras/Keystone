## Upgrade migration verified against a populated 1.7 database

- `totp_backup_codes.expires_at` is backfilled to `created_at + 90 days` and
  made `NOT NULL` without failing on existing rows.
- Existing `totpSecret` values (legacy AES-CBC) are preserved untouched;
  `totp_last_step` starts `NULL`.
- Existing `refresh_tokens.mfa_factor` starts `NULL`, so a session created before
  MFA was enabled can no longer be rotated into a new one.
- `mfa_challenges` is created empty.
